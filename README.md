# Glide China — AI Travel Companion

Glide China is a six-person team prototype designed to help international travellers navigate China through multilingual travel support, local-app guidance, mock or configurable AI assistance, translation and speech interfaces, itinerary tools, weather support, and community-oriented screens.

## Team contribution

Neha Elsa Renji contributed to quality assurance and testing, test-case design, release-readiness work, and presentation support.

## Technology used

- Flutter/Dart with Provider and Dio for the mobile prototype.
- Python, FastAPI, SQLAlchemy, Pydantic Settings, and JWT-based sessions for the backend prototype.
- Mock or configurable integrations for chat, translation, speech, weather, and mapping services.

## Public release status

This repository currently publishes the project overview only. The full team source and assets are withheld while an explicit public-release confirmation is obtained because the prototype contains authentication, identity-document, location, social, and external-service flows.

No API keys, tokens, databases, user records, or local configuration are published here.
